# KenPanel App Capsule

> Next-gen containerization, application isolation, and one-click app packaging engine for KenPanel.

## Components

- untime/ - Lightweight container runtime interface and cgroups/namespace manager
- packager/ - App bundle packager, manifest parser, and dependency resolver
- 	emplates/ - Curated one-click application recipes (WordPress, Next.js, Ghost, etc.)
- cli/ - capsule CLI tool for local testing and building
